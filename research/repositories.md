# Repository review

The input notes named projects without repository URLs. Their companion research file disambiguated several names. The table covers 30 repositories and two official platform examples. Findings refer to the pinned files and the specific example reviewed. A project can contain many other strategies. All the application code in this lab was written for this experiment. Upstream source is linked for inspection.

## Reported profits

The notes give eye-catching percentages for community backtests, an LLM run, and version changes. None of the inspected material tied those particular numbers to a dated, independently reconciled live account statement with capital flows, costs and drawdown. They are excluded from the performance table. Published simulations, infrastructure examples and this project’s own simulated fills remain identifiable as such.
